# Competitive Programming and Algorithms

This repository is a personal collection of C++ implementations focused on competitive programming, algorithms, and data structures. It serves both as a study notebook and as a reusable reference library for common problem-solving patterns.

## What is included

The repository contains examples and templates covering:

- Fundamentals such as STL usage, sorting, binary search, prefix sums, and two pointers
- Core data structures including stacks, queues, disjoint set union, Fenwick trees, and segment trees
- Dynamic programming techniques such as Fibonacci, knapsack, and optimization problems
- Graph algorithms including BFS, DFS, Dijkstra, minimum spanning trees, and TSP approaches
- Number theory topics such as gcd, primality, and prime factorization
- Recursive and backtracking solutions
- Reusable C++ templates for competitive programming

## Purpose

The main goal is to document and practice standard algorithmic ideas in a structured way. The code is intended to be educational, easy to read, and useful as a starting point for solving contest problems.

## Notes

- Most files are standalone C++ programs meant for learning and experimentation.
- The style is simple and instructional rather than production-oriented.
- Feel free to use these examples as a reference while preparing for contests or reviewing algorithms.
